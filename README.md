# DevOps Integrated Project

A simple DevOps project demonstrating CI/CD using GitHub, Jenkins, Docker, and Docker Compose on AWS EC2.

## Tools Used

* GitHub
* Jenkins
* Docker
* Docker Compose
* AWS EC2
* Nginx

## Workflow

GitHub → Jenkins → Docker Compose → Docker Container → Live Website

## Features

* Dockerized web application
* Automated deployment with Jenkins
* GitHub integration
* Docker Compose orchestration
* Hosted on AWS EC2
